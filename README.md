# backend

Serwer aplikacji logistycznej – centralny element systemu wspomagającego planowanie i monitorowanie transportu.

## Za co odpowiada

- Przechowywanie planów tras (odcinki i postoje) oraz danych transportowych.
- Odbieranie lokalizacji GPS i prędkości z aplikacji mobilnej kierowcy.
- Aktualizowanie statusów realizacji tras, odcinków i postojów.
- Obliczanie przewidywanego czasu przyjazdu (ETA) do kolejnych punktów trasy.
- Udostępnianie danych aplikacji webowej (dyspozytor, klient) i mobilnej (kierowca) poprzez API.
- Kontrola dostępu – klient widzi wyłącznie informacje o swoim przejeździe.

## Powiązane repozytoria

- [frontend](https://github.com/Projekt-grupowy-2026/frontend) – aplikacja webowa dla dyspozytora i klienta.
- [mobile-app](https://github.com/Projekt-grupowy-2026/mobile-app) – aplikacja mobilna dla kierowcy.
